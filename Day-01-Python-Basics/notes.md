# 📝 Day 01 Notes: Python Introduction & Basics

## Concepts Covered:
1. **Printing Output**:
   - `print()` function console par message display karne ke liye use hota hai.
   - `sep` aur `end` parameters print ke formatting controls hain.



2. **Data Types in Python**:
   - `str` (String): Text data, quotes ke andar (`"Hello"`, `'Python'`)
   - `int` (Integer): Baghair decimal ke whole numbers (`10`, `-5`)
   - `float` (Float): Decimal wale numbers (`3.14`, `0.5`)
   - `bool` (Boolean): Sirf do values: `True` ya `False`

3. **Arithmetic Operators**:
   - `+`, `-`, `*`, `/`
   - `//` Floor division (sirf integer hissa deta hai)
   - `%` Modulo (remainder deta hai)
   - `**` Exponent / Power

4. **Variables Naming Rules**:
   - Variable name letter ya underscore `_` se shuru hona chahiye.
   - Case-sensitive hote hain (`name` aur `Name` alag hain).
   - Python mein recommended style: `snake_case` (e.g., `user_name`, `total_marks`).
